## 視覺

底子是社團 IG 貼文的視覺語言：白＋淺藍＋品牌深藍、藍青大氣柔光、霧面玻璃卡、圓角膠囊、iOS 清單列。

上面疊了一條**貫穿整頁的莫比烏斯帶**。重點是它只有**一條**：幾何在瀏覽器裡用「整份文件的座標」算出來，每個區塊看到的都是同一條帶子的不同片段，不是每區各放一段裝飾。

幾個實作上要知道的事：

- **奇數個半扭轉**。莫比烏斯的單面性只要求半扭轉次數是奇數，所以桌機用 3、手機用 5，都仍然是真的莫比烏斯帶。用 1 的話，整頁高度才轉半圈，肉眼看不出它在轉。
- **沿著唯一那條邊跑的光點**。莫比烏斯帶的邊界只有一條，所以那顆光點要把整頁走兩遍才回到原點。
- **不要在 `.mob` 上加 `filter: blur()`**。那一層有整頁那麼高，實測捲動時 frame 中位數會從 16.7ms 掉到 33.4ms（60fps → 30fps）。柔光是用三層由寬到窄的描邊疊出來的。
- **冰藍底色不歸區塊所有**。它是 `.mob-bg` 這一整張羽化過的場，因為帶子必須從區塊底色後面穿過去。只有真的長出這張場的頁面才會套用（`html.mob-on`），其他頁維持原本的冰藍實塊。

無障礙：全站文字對比度以「字元像素級」量過，121 個文字元素**全部通過 WCAG AA**，最低 4.68:1。所有動效都有 `prefers-reduced-motion` 保護。
