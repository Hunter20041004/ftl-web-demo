# Glass V6 改版設計（2026-09-12）

## 決定了什麼
使用者看過 Next.js 重建版（`rebuild/v1-on-new-architecture`）後認為線條太生硬、與柔和漸層背景不搭，要求大改版。參考 agentcat.com 與 anchr.tech 的**手法**（材質、字級、動效），**不採用它們的色調**。

| 問題 | 決定 |
|---|---|
| 基底 | `rebuild/v1-on-new-architecture` → 新分支 `redesign/glass-v6` |
| 首屏主視覺 | 右側 logo 線條動畫：三條線沿手描骨架路徑畫入 → 淡入 PNG 原圖（方案 B，無向量檔） |
| 首屏左側 | 靜態標題，不做打字機 |
| 四個問題清單 | 整段移除 |
| 首屏數據列 | 移除（四個數字皆為示意資料） |
| 交易網絡裝飾 | 四處全部移除，連同其 CSS、元件、測試 |
| 範圍 | 7 頁全部重新設計（分階段：首頁先、內頁後） |
| 深色模式 | 不做；色調完全沿用 `ftl.css` 既有變數 |
| 字體 | 英文 Outfit、中文 LINE Seed TC、等寬 IBM Plex Mono |

## 材質系統：零硬線
- 不再用 1px 實線分層。卡片＝`rgba(255,255,255,.66)` ＋ `backdrop-filter: blur` ＋ 內側 1px 白色高光 ＋ 陰影 `0 12px 34px rgba(11,31,58,.05)`。
- 背景：既有冰藍→白漸層 ＋ 極淡點陣（24px 間距、`--line` 40% 透明）。
- 區塊之間無分隔線，靠留白（96 / 128px 交替）與背景明暗微差。清單列＝8px 間距的獨立玻璃列。
- 圓角三檔：12 / 20 / 28px。

## 字級
H1 `clamp(40px,6vw,72px)` 字重 300–500（英）／700（中）；H2 `clamp(32px,4vw,48px)`；內文 17px、行高 1.7。

## 首頁結構
首屏（標題＋副標＋兩顆 CTA｜logo 動畫）→ 社團宗旨（捲動填色大字＋三張玻璃卡）→ FinTech 週報（一大兩小）→ 近期活動（三卡）→ 聯絡我們（藍面板＋四個社群玻璃列）→ 合作對象（跑馬燈，玻璃方塊）。
一頁只有一個主角動畫（logo）；其他只做進場淡入與 hover 微浮 4px。

## Logo 動畫規格
1. 手描 F、T、L 三筆緞帶中心線為 SVG 路徑，描邊 6px、品牌藍→青色漸層。
2. 載入後 0.3s 起，三條線各從左外／右外／上外飛入並沿路徑描邊，總長 1.4s，錯開 0.15s，緩動 `cubic-bezier(.22,1,.36,1)`。
3. 約 1.6s：線稿 0.5s 淡出，PNG 同步淡入並 96%→100% 縮放。
4. 完成後僅極慢浮動（8s 循環、6px）。
5. `prefers-reduced-motion`：直接顯示 PNG。手機：logo 移到標題下方、220px 寬。
6. 只跑一次。

## 內頁
沿用各頁資訊順序，統一為「大標區＋玻璃卡／玻璃列」骨架，套用同一材質與字級。

## 不做
打字機、scrollspy 小導覽、深色模式、粒子聚合、新增主色。
