# 週報貼上格式

後台「週報 → 新增一期 → 貼上整份週報 → 拆解」認得的格式。週報 Prompt 請改成直接輸出這個格式。

規則：
- 每個欄位一行標記 `【…】`，中文標記與英文標記成對出現（英文標記用英文字）。
- 清單型欄位（重點、接下來、來源）在標記下一行起，一行一條，`- ` 開頭。
- 說法：`【說法】原話｜誰說的`；沒有就整段省略。名詞也可省略。
- 來源：`- 標籤｜英文標籤｜網址｜一手`，一手來源才寫最後一段。
- 三則之間用一行 `---` 隔開。第一段是本期一句話。

```
【本期一句話】…
【Issue lede】…
---
【短標】建議 12 字內，最多 24 字（外商公司名可較長）
【Headline】…
【標題】…
【Title】…
【一句話】…
【Lede】…
【重點】
- …
- …
【Facts】
- …
- …
【背景】…
【Context】…
【說法】原話｜誰說的
【Quote】Quote｜Who
【為什麼重要】…
【Why】…
【台灣視角】…
【Taiwan】…
【接下來】
- …
【Watch】
- …
【名詞】…（可省略）
【Term】…
【來源】
- 標籤｜Label｜https://…｜一手
- 標籤｜Label｜https://…
---
（第二則）
---
（第三則）
```

拆解後缺的欄位會標黃並提示，補齊再發布。每則欄位的意義見 `docs/週報編輯規範.md`。
