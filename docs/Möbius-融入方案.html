Design proposal · 2026-09-09

把莫比烏斯環
放進 FTL 官網

不動版型、不破壞現有主視覺的前提下，把「連續、翻轉、閉環」變成這個站的結構語言。 以下所有幾何都是用標準參數式算出來的真莫比烏斯，不是無限符號。

A現況分析

為什麼這個站「本來就適合」莫比烏斯

最強的理由不是概念好聽，是你們的 logo 本身就是一條扭轉、交疊的帶子——FTL 的字標由一條連續緞帶摺出來，有摺痕（受光變亮）、有交疊（壓過去變暗）、有圓鈍收尾。莫比烏斯不是外來的裝飾，它是把已經存在於商標裡的形式語言，放大成整個網站的結構。

實測現況值對莫比烏斯的意義
Hero 已有分層光暈 z=0（1459×823）、巨型「創新」z=0、清單玻璃片 505×428、數據玻璃片 520×132（z=2，往上壓 71px）已經有「背景層 → 被糊的東西 → 玻璃片」三層。緞帶直接放進「被糊的東西」那一層即可，不需要新增結構
玻璃片有真的 backdrop-filterblur(30px) saturate(1.95)緞帶穿過玻璃片時會自然糊掉一段——這正是莫比烏斯「同一條帶子翻到另一面」的視覺對應
背景已是曲面光暈4 個 radial-gradient光源已經在了。緞帶不需要自己發光，只要被光暈打亮
段落節奏白 → 冰藍 → 白 → 冰藍 → 白 → 白，總高 4421px切換處目前是硬邊。這是放「單線軌跡」最自然的位置
色票主藍 #1668E3、深藍 #0A46B4、墨 #0B1F3A、紙 #FBFAFF緞帶只用這三支藍的不同透明度就夠，不引入新色

最適合的三個位置：

  • Hero 右側背景層（目前巨型「創新」的位置）——已經有玻璃片會壓在上面，穿插關係現成
  • 段落之間的切換——白↔冰藍的硬邊，正好用一段連續曲線接起來
  • 卡片 hover——目前只有位移，缺一個「這個品牌自己的」回饋動作
B三個方案

由輕到重，都不動版型

下面三張是用真的莫比烏斯參數式算出來的：x=(R+v·cos(u/2))·cos u，y=(R+v·cos(u/2))·sin u，z=v·sin(u/2)。 驗證過 u=0 與 u=4π 同點、u=2π 落在另一側——確實只有一條邊。
⚠️ 預覽為了看清楚把線加粗了（2.2px、62%）；正式站用 1.2–1.6px、18–26%，實際上會淡很多。

C邊界

可以加、不要動、太重了

✓ 可以加

  • Hero 右側背景層（巨型「創新」現在的位置）
  • 白↔冰藍段落交界，用一段曲線接
  • 卡片 hover 時右上角浮出一小段 loop
  • 頁尾一條收束的弧
  • 週報／活動的編號旁邊一小段扭轉記號

✗ 不要動

  • 兩片玻璃的位置與 71px 交疊——這個構圖已經定了
  • 清單列本身（那是社群圖的核心語彙）
  • CTA 的漸層與青色光暈
  • 導覽列、logo
  • 白／冰藍的段落節奏
  • 標題的字級與字重

⚠ 太重

  • WebGL／three.js 的 3D 旋轉環——會殺掉整站的安靜，也跟玻璃打架
  • 莫比烏斯當重複底紋（變壁紙）
  • 每個段落都放一個
  • 轉速快於 120 秒／圈
  • 非品牌色的漸層（紫、橘、霓虹）
  • 緞帶壓在任何文字上
D實作

優先做這三件事

01

把巨型「創新」換成莫比烏斯邊緣線

同一個位置、同一層（z=0）、同樣被玻璃片糊。SVG 內嵌，不需要 JS。線寬 1.2–1.6px、stroke-opacity 0.18–0.26。

02

段落交界用同一條曲線的一小段

白↔冰藍的硬邊改成一段 120px 高的弧。取邊緣路徑的一小段即可，整站共用同一個 SVG symbol，語言才會一致。

03

卡片 hover 浮出一小段 loop

目前 hover 只有位移。加一段 stroke-dashoffset 動畫，180ms 畫出一小圈。這是唯一「使用者主動觸發」的莫比烏斯，成本最低但記憶點最強。

技術選擇

做法適合判斷
純 SVG ＋ CSS方案 1、2、3 全部建議用這個。路徑是靜態的，動效交給 CSS stroke-dashoffset 與 transform:rotate，跑在合成執行緒上，不吃主執行緒
Canvas 2D要讓緞帶隨滑鼠變形不必要。這個站的調性不需要跟隨滑鼠
WebGL / three.js真 3D、真材質不建議。檔案大、耗電、與「安靜克制」的要求衝突

路徑怎麼來的（可直接交給前端）

# 標準莫比烏斯參數式；u 走 0 → 4π 才回到原點，這就是「只有一條邊」
x = (R + v·cos(u/2))·cos(u)
y = (R + v·cos(u/2))·sin(u)
z = v·sin(u/2)

# 投影到 2D：先繞 z 轉 roll，再往後傾 tilt
X  = x·cos(roll) − y·sin(roll)
Y' = (x·sin(roll) + y·cos(roll))·cos(tilt) − z·sin(tilt)
depth = (x·sin(roll) + y·cos(roll))·sin(tilt) + z·cos(tilt)   # 依此排序做前後遮擋

# 本頁用的參數
R = 1.0    v = ±0.34    roll = 0.30    tilt = 0.62    取樣 520 點

動效參數

  • 整體旋轉：150 秒／圈，linear。慢到你不會注意到它在動，但每次回來畫面都不一樣
  • 光流：stroke-dasharray: 120 3200，26 秒跑完一圈
  • Hover loop：180ms，cubic-bezier(.23,1,.32,1)
  • 全部包在 @media (prefers-reduced-motion: reduce) 裡關掉

上線前必須量的三件事

  • 緞帶最亮處的顏色，對它量所有文字的對比（用字元層級量測，不要量整個方框——方框邊緣會壓到裝飾，量出來的數字是假的）
  • 375px 下 document.documentElement.scrollWidth 必須等於 375
  • SVG 是否被 .blue-field > * 之類的規則覆蓋成 position:relative——這個站已經踩過兩次，裝飾層被推進正常流會把內容擠掉
